# Adino Designs — Editable Website

A responsive, single-page website built with editable HTML and CSS.

## Files
- `index.html` — all page structure, styles, navigation, and responsive breakpoints.
- `assets/adino-brand-hero.png` — supplied Adino Designs brand mockup used as the hero image.

## Preview locally
Open `index.html` in a modern browser. An internet connection is required to load the Poppins font. All layout and styling are editable directly in `index.html`.

## Customize
- Change the hero image by replacing `assets/adino-brand-hero.png` with another image and updating the `<img>` path if its filename changes.
- Edit text in the `.intro` section.
- Update contact links in the `.contact` section.
- Adjust mobile layout in the `@media (max-width: 640px)` and `@media (max-width: 360px)` CSS rules.

## Notes
This is a standalone, downloadable version of the website. It is separate from the React/TypeScript files in the Floot project.
